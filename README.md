# looksie..

builds of looksie.. (a sample browser plugin + sampler rack). the app checks here once a day for updates.

## which file do i download?

open the [newest release](https://github.com/adrnagain/looksie/releases) for your system and download the zip under **assets**:

| your computer | download |
|---|---|
| **windows 10 / 11** (64-bit) | `looksie-vX-bN-Windows-10-11-64bit.zip` |
| **mac with apple silicon** (m1–m4), macos 12 or newer | `looksie-vX-bN-Mac-AppleSilicon-macOS12-or-newer.zip` |

intel macs and linux aren't supported yet.

## install

1. unzip it.
2. close your daw.
3. double-click **`install.bat`** (windows) or **`install.command`** (mac).
4. rescan plugins in your daw.

each zip has a **`HOW TO INSTALL`** file with the full steps, including what to click when windows or macos warns about an unsigned app.

after the first install the app tells you about new versions, and its **update** button installs them. you can turn this off under settings > updates.

(the `channel` release only holds the small files the app checks. don't download from it.)
